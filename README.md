# proyecto-manila
Restaurante MANILA es una app en Angular para gestionar pedidos de comida y bebida consumiendo APIs externas (TheMealDB y TheCocktailDB). Incluye filtros, carrito reactivo con Signals y localStorage, descarga de comprobantes en PDF y un juego de memoria interactivo 4x4. Desarrollada por Jhoan Stiven Maya Tonuzco para Ingeniería en Informática.
